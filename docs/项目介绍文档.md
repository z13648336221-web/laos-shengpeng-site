# 重庆恒慈国际贸易有限公司官网项目介绍

---

## 一、项目概述

### 1.1 项目定位

**重庆恒慈国际贸易有限公司官网**是一家专注东南亚跨境物流的专业服务平台，致力于为跨境电商和进出口贸易企业提供高效、稳定、可追踪的国际物流解决方案。

### 1.2 核心服务

| 服务类型 | 运输路线 | 时效 | 特点 |
|---------|---------|------|------|
| 🚂 中老铁路陆运 | 昆明 → 万象 | 5-7天 | 全程铁路直达，稳定性高 |
| 🚢 泰国海运 | 广州/深圳 → 曼谷 | 7-12天 | 每周三班，整柜/散货均可 |
| ⚓ 越南海运 | 广州/深圳 → 胡志明 | 5-8天 | 每日开港，快速便捷 |

### 1.3 目标用户

- **跨境电商企业**：需要稳定的跨境物流服务支持海外仓备货
- **进出口贸易公司**：需要专业的清关和门到门服务
- **生产制造企业**：需要批量货物运输到东南亚市场
- **个体商户**：需要灵活的小批量运输方案

## 二、主要功能介绍

### 2.1 在线询价系统

用户可以通过在线表单快速获取物流报价：

1. **填写运输信息**：选择运输方式、输入货物详情
2. **即时报价**：系统自动计算费用，透明展示
3. **多种方案对比**：可对比不同运输方式的价格和时效

### 2.2 货物追踪系统

实现全程可视化追踪：

- **实时位置查询**：输入运单号即可查看货物当前状态
- **节点更新提醒**：关键节点自动推送通知
- **轨迹回放**：查看货物运输全程路线

### 2.3 多语言支持

支持三种语言实时切换：

- 🇨🇳 中文（默认）
- 🇬🇧 英文
- 🇻🇳 越南语

### 2.4 新闻资讯

提供行业动态和公司新闻：

- 物流行业政策解读
- 航线调整通知
- 公司服务升级公告

## 六、使用指南

### 6.1 访问网站

**前端访问地址**：`http://localhost:8000`

**管理后台**：`http://localhost:8000/admin-login.html`

### 6.2 快速开始

1. **浏览服务**：访问首页了解三大核心业务
2. **在线询价**：填写运输信息获取报价
3. **货物追踪**：输入运单号查询物流状态
4. **联系客服**：点击右下角客服图标即时咨询

### 6.3 技术启动（开发者）

**启动前端服务**：
```bash
python -m http.server 8000
```

**启动后端服务**：
```bash
cd backend
npm install
node server.js
```
